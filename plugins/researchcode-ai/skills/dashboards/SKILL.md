# Dashboards

## Workflow
Define metric numerator/denominator, grain, refresh schedule, data source, effective date, publication tier and missing-data semantics. For replication-dashboard views show candidate vs verified vs reproduced separately; never imply candidate links were validated. Charts must preserve scale, confidence intervals and units. Add drilldown to paper DOI, code repository, dataset license and execution log. For audit dashboards, hide client identifiers, respect permissions and mark findings as preliminary until independently reviewed.
