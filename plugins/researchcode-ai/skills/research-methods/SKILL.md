# Research Methods

## Workflow
Recover DV, IV, population, sample period and unit of observation. Identify whether design is panel FE/RE, DiD, IV, RDD, event study, matching, machine learning or qualitative. Translate variables into precise formulas and units, explicitly distinguishing observable free data from paid providers.

For panel FE: identify entity and period effects, clustered errors and variation source. For DiD: discuss treatment definition, anticipation, parallel trends, event-time coefficients, staggered-adoption estimator limitations and interference. For IV: exclusion restriction, relevance, weak instrument tests and overidentification. For ML: temporal split, data leakage, class imbalance, calibration, explanation limitations and external validity.

Produce pre-registered hypotheses only as proposals, and never claim statistical significance without executing a model on actual data. Distinguish descriptive associations from causal effects; attach reproducible scripts and seeds when code execution is authorized.
