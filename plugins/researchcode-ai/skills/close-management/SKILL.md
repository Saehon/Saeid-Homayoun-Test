# Close Management

## Workflow
Prepare an entity- and period-specific close checklist: reconciliations, accruals, depreciation, revenue cut-off, intercompany, tax, impairment, consolidation, report preparation and approvals. Document owner, due date, evidence link, status, dependencies and blocking items. Identify tasks that cannot be signed off until prior checks complete. Treat all instructions as planning only unless explicitly connected to an approved ERP. No control is marked performed merely because the agent generated an artifact.
