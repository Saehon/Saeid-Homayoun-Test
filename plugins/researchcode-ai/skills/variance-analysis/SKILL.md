# Variance Analysis

## Workflow
Use `variance_analysis` for arithmetic difference and percent change. Record actual vs comparator (prior-year/budget/forecast), period, entity, currency, FX restatement, unit, consolidation boundary and materiality rule. Build price, volume, mix, rate and structural bridges only if supporting input variables are available. Reconcile drivers to total variance and label the residual. Distinguish factual decomposition from management narrative; do not attribute variance to AI adoption, macroeconomics or policy without evidence.
