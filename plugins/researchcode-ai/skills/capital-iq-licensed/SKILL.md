# Capital Iq Licensed

## Boundary
S&P Capital IQ / Kensho is an external licensed provider, **not a free dataset**, and this package does not embed its API or credentials. If the researcher already has an authorized connector, request an explicit connection and permissions; otherwise prefer SEC EDGAR, FRED, World Bank and other public sources for a free-data study.

## Procedure
For licensed usage, document entitlement, redistribution and derived-data restrictions, source retrieval time and vendor identifiers. Do not scrape paywalled webpages or expose licensed tear sheets in public archives. Disclose when earnings previews, proprietary estimates and financial metrics are unavailable.
