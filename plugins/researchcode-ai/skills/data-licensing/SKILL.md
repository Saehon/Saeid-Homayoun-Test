# Data Licensing

## Procedure
For every data source record provider, URL, access date, license URL, redistributability, user authorization, raw versus derivative status and restrictions on AI-assisted processing. Mark WRDS/Compustat, CRSP, Refinitiv, Bloomberg, Capital IQ, Audit Analytics and institutionally licensed sources `restricted_by_default` unless the specific grant says otherwise.

Do not put credentials, proprietary rankings, downloaded licensed observations or private papers in a public GitHub repository or share via a public plugin. Keep data hashes and processing instructions but not restricted data. Open government data may still have attribution, rate, security and terms-of-use obligations. Where API contracts disallow automated bulk retrieval, stop and surface the restriction.
