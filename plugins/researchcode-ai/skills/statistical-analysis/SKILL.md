# Statistical Analysis

## Workflow
Translate a research question to estimand, variables, sampling frame and identification strategy; select descriptive checks, regression models, clustering, multiple-testing adjustments and robustness. For regression output, require original data and actual execution: never invent coefficients, significance, confidence intervals or model fit.

Supply explicit Python/R/Stata scripts with package versions and seeds for replication, and diagnostics for influential observations, model assumptions and sensitivity. If statistical code has not been executed, mark it `proposed_not_run`. Disclose plausible alternative explanations and inference limitations.
